# Социальная сеть «Демо» (Full-Stack React 19 + Go)

Современная веб-платформа нового поколения в светлом дизайне, объединяющая возможности ключевых сервисов:
- 📸 **Лента и посты (Instagram-стиль)**: сторис-карточки, интерактивные публикации, лайки двойным кликом, комментарии, ответы и реакции.
- 📹 **Видео и видеоканал (YouTube-стиль)**: просмотр видео, плеер, персональные каналы (`/channel/me`), баннеры, вкладки (*Главная, Видео, Плейлисты, Сообщество, О канале*), загрузка видео и настройка оформления.
- 💬 **Мессенджер (Telegram-стиль)**: диалоги, онлайн-статусы, голосовые сообщения с визуализацией волны, прикрепление файлов и медиа.
- 📞 **Конференции (Zoom / Google Meet-стиль)**: видеозвонки, автоматическое создание группового чата, сохранение записей, закрытые и открытые конференции.
- 🎙️ **Подкасты**: каталог выпусков, аудиоплеер с прогресс-баром и фоновым воспроизведением.
- ⚙️ **Профиль и Канал**: редактирование аватара, обложки, никнейма, описания, соцсетей и статуса онлайн с мгновенным обновлением.
- 🔍 **Глобальный поиск**: умный поиск пользователей, постов, видео и подкастов из шапки.

---

## 🚀 Развёртывание на Railway

Проект полностью подготовлен для деплоя на [Railway](https://railway.app):
- Настроен многоэтапный `Dockerfile` (сборка React 19 через Node 22 + компиляция легковесного Go-бинарника).
- Настроен `railway.json` с healthcheck (`/api/health`).
- В продакшене единый Go-сервер отдаёт собранный React SPA со всеми маршрутами (`SPA Fallback`) и обслуживает `/api/*`.

### Быстрый деплой:
1. Зайдите в [Railway.app](https://railway.app).
2. Нажмите **New Project** → **Deploy from GitHub repo**.
3. Выберите репозиторий `Claower3D/soc`.
4. Railway автоматически обнаружит `Dockerfile` и запустит сборку. Приложение будет доступно по сгенерированному HTTPS-домену.

## 💻 Локальный запуск

### 1. Бэкенд (Go, порт 8080)
```bash
cd backend
go run .
```

### 2. Фронтенд (React 19 + Vite)
```bash
cd frontend
npm install
npm run dev
```

### 3. Запуск через Docker
```bash
docker build -t soc-app .
docker run -p 8080:8080 soc-app
```
Сервис будет доступен по адресу: `http://localhost:8080`
